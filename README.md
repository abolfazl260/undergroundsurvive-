# Underground Survive

بازی دوبعدی ساخت و مدیریت پناهگاه، با امکان توسعهٔ ساختمان در **سطح زمین و زیرزمین**، مدیریت بازماندگان، دفاع از پایگاه و تعامل آنلاین با بازیکنان دیگر.

**پلتفرم‌های هدف:** وب (مرورگر/PWA)، Android و iOS با یک کد مشترک  
**وضعیت پروژه:** برنامه‌ریزی و مستندسازی قابلیت‌ها؛ این README نشان‌دهندهٔ پیاده‌سازی یا انتشار بازی نیست.

## معماری انتخاب‌شده (Web-First)

- **Phaser + TypeScript + Vite:** موتور دوبعدی و نسخهٔ وب.
- **Supabase:** هویت، PostgreSQL، ذخیرهٔ آنلاین، عملیات معتبر سمت سرور و Realtime در صورت نیاز.
- **Capacitor:** بسته‌بندی همان بازی برای Android و iOS.
- **ساختار:** ماژول‌های مستقل بر اساس قابلیت (World، Building، Economy، Characters و غیره)؛ بدون Microservice یا سرور اختصاصی پیچیده در شروع.
- **اصل امنیتی:** کسر سکه، ساخت اتاق، مالکیت اسکین و نتیجهٔ نبرد در سرور اعتبارسنجی شوند.

[جزئیات و ساختار پوشه‌ها در سند معماری](Docs/ARCHITECTURE.md)

## اجرای نسخهٔ اولیهٔ وب

کد اجرایی در [پوشهٔ game](game/) قرار دارد. برای اجرای محلی به Node.js 22.12+ نیاز دارید:

~~~bash
cd game
npm install
npm run dev
~~~

سپس http://localhost:5173 را باز کنید. راهنما: [game/README.md](game/README.md). این نسخه فقط نمونهٔ آزمایشی محلی است؛ هنوز روی دامنهٔ عمومی منتشر نشده و اتصال Supabase یا ذخیرهٔ آنلاین ندارد.

## انتشار آنلاین نسخهٔ آزمایشی

فایل Workflow استقرار روی GitHub Pages در `.github/workflows/deploy-web.yml` اضافه شده است. **فعال‌کردن GitHub Pages هنوز به اقدام مالک مخزن نیاز دارد**؛ ساخت و تست خودکار موفق بوده‌اند اما سایت عمومی هنوز منتشر نشده است.

برای فعال‌سازی، در GitHub مسیر **Settings → Pages → Build and deployment → Source: GitHub Actions** را انتخاب کنید. سپس Workflow با نام **Deploy web prototype to GitHub Pages** را از بخش Actions دوباره اجرا کنید. پس از موفقیت استقرار، آدرس نهایی در خروجی همان Workflow نمایش داده می‌شود.

## اولویت توسعه (Development Roadmap)

این نقشهٔ راه **پیشنهادی** است. علامت‌های خالی به معنی **برنامه‌ریزی‌شده، نه تکمیل‌شده** هستند. ترتیب توسعه وابستگی‌های فنی را رعایت می‌کند: قابلیت آنلاین از ابتدا زیرساخت دارد، اما اتحاد و جنگ آنلاین پس از تکمیل هستهٔ بازی اضافه می‌شوند.

### P0 — پایهٔ فنی Web-First
- [x] راه‌اندازی Phaser + TypeScript + Vite و نسخهٔ وب آزمایشی قابل اجرا در محیط محلی
- [ ] پیاده‌سازی ساختار ماژول‌های مستقل و قراردادهای مشترک
- [ ] **F-02 (بخش پایه):** اتصال Supabase Auth و ذخیره/بازیابی امن اطلاعات آزمایشی پایگاه
- [ ] **F-01 (بخش پایه):** آماده‌سازی طرح خروجی Android و iOS با Capacitor

**معیار خروج:** نسخهٔ وب در مرورگر اجرا شود و دادهٔ آزمایشی بازیکن با کنترل دسترسی صحیح ذخیره و بازیابی شود.

- [x] نمونهٔ قابل‌بازی محلی: حفاری، آزادسازی طبقه، ساخت، تخریب، انتقال و ارتقای آزمایشی اتاق‌ها همراه ذخیرهٔ مرورگر
- [ ] **F-03:** ساخت دوبعدی اتاق‌ها؛ انتخاب محل، ساخت و تخریب (نمونهٔ محلی پیاده‌سازی شد؛ اتصال سرور و اقتصاد باقی است)
- [ ] **F-04:** افزایش ارتفاع ساختمان و حفاری/گسترش زیرزمین (نمونهٔ محدود محلی آماده است)
