# قوانین، حریم خصوصی و دسترسی‌های بازی (نسخهٔ آزمایشی)

**تاریخ بازبینی:** 2026-10-31  
**وضعیت:** اطلاع‌رسانی محصول در مرحلهٔ توسعه؛ این متن جایگزین بازبینی حقوقی، سیاست رسمی منتشرشده یا اظهارنامهٔ فروشگاه نیست.

## محل نمایش در بازی

از **منوی اصلی / منوی توقف → قوانین و دسترسی‌ها** و **تنظیمات → قوانین و دسترسی‌ها** قابل مشاهده است. صفحه در وب و WebView اندروید یکسان عمل می‌کند، به زبان فارسی/انگلیسی ترجمه شده و دارای پنج بخش بازشونده است:

1. قوانین و محدودیت‌های بازی: ساخت‌وساز فقط زیرزمین، اتصال اتاق‌ها به آسانسور، توسعهٔ شفت، هزینه‌ها، منابع و ارتقا.
2. شرایط استفاده: وضعیت نمونهٔ آزمایشی، ماهیت مجازی سکه‌ها و داستان، نبود پرداخت واقعی یا حساب آنلاین، و لزوم بررسی حقوق دارایی‌های هنری.
3. حریم خصوصی: انواع داده‌های محلی، چرخهٔ نگهداری، دادهٔ بازیابی، محدودیت انتقال و حذف داده‌ها.
4. مجوزهای دستگاه: حافظهٔ محلی، اینترنت و پخش صدا در برابر دوربین، میکروفون، مکان، رسانه‌های خصوصی، مخاطبان، اعلان و ردیابی.
5. امنیت و پشتیبانی: غیرقابل‌اتکا بودن موجودی کلاینت برای اقتصاد واقعی، گزارش مشکل، اعلام تغییر سیاست و نیاز به ممیزی انتشار.

منبع متن دو‌زبانه: `game/src/app/policies.ts` و تست‌ها: `game/src/app/policies.test.ts`.

## ممیزی واقعی داده‌های ذخیره‌شده

| داده | کلید فعلی | محل/هدف |
| --- | --- | --- |
| پیشرفت، نقشه، بازماندگان، منابع، کیف پول، تاریخچهٔ تراکنش‌ها | `underground-survive:game:v2` | `localStorage`؛ ادامهٔ بازی |
| ذخیرهٔ قدیمی | `underground-survive:base:v1` | فقط خواندن برای بازیابی نسخه‌های قبلی |
| نسخهٔ بازیابی دادهٔ نامعتبر | `underground-survive:recovery` | نگهداری احتمالی نسخهٔ قبلی در همان دستگاه |
| زبان بازی | `underground-survive:language:v1` | `localStorage`؛ ترجیح فارسی/انگلیسی |
| صدای بازی | `underground-survive:audio:v1` | `localStorage`؛ بی‌صدا، موسیقی، افکت و حجم |
| کاهش حرکت | `underground-survive:menu-settings:v1` | `localStorage`؛ دسترس‌پذیری |
| وضعیت فصل‌های داستان | `underground:story-progress:v1` | `localStorage`؛ پیگیری فصل‌های مشاهده‌شده |

- **حذف:** مرورگر → تنظیمات سایت → پاک‌کردن داده‌های همین سایت؛ اندروید → تنظیمات برنامه → پاک‌کردن داده‌ها. حذف داده ممکن است غیرقابل‌بازگشت باشد. گزینهٔ «شروع بازی جدید» همهٔ کلیدهای ترجیحات و بازیابی را پاک نمی‌کند و نباید جایگزین حذف کامل داده‌ها معرفی شود.
- **انتقال:** ذخیرهٔ وب و اپ اندروید به یکدیگر به‌صورت خودکار منتقل نمی‌شوند؛ برای همگام‌سازی به زیرساخت مستقلی نیاز است.
- **شبکه:** کد فعلی از حساب سروری، همگام‌سازی ابری یا سرویس تحلیل رفتار بازیکن استفاده نمی‌کند. بارگذاری سایت/دارایی‌ها مستلزم ارتباط با میزبان است و لاگ‌های ارتباطی احتمالی خارج از `localStorage` و تابع سیاست میزبان هستند.
- **امنیت:** `localStorage` از نظر یکپارچگی برای اقتصاد آنلاین قابل اعتماد نیست؛ در صورت افزودن پرداخت، پاداش مالی، رقابت یا حساب سروری، قوانین و موجودی باید در سمت سرور اعتبارسنجی شوند.

## وضعیت مجوزهای دستگاه

| دسترسی | وضعیت فعلی |
| --- | --- |
| ذخیرهٔ محلی مرورگر / WebView | مورد استفاده؛ مجوز فایل‌های شخصی نیست |
| شبکه | نسخه وب برای بارگذاری سایت؛ نسخه Android فایل‌های بازی را بسته‌بندی می‌کند؛ **مجوزهای نهایی AndroidManifest باید جداگانه بررسی شوند** |
| پخش موسیقی و افکت | مورد استفاده بعد از تعامل کاربر؛ بدون نیاز به ضبط صدا |
| دوربین / میکروفون / موقعیت مکانی | در کد فعلی درخواستی وجود ندارد |
| پیامک / مخاطبان / تماس‌ها / عکس‌ها و فایل‌های خصوصی | در کد فعلی درخواستی وجود ندارد |
| اعلان پوش / شناسهٔ تبلیغاتی / موقعیت پس‌زمینه | در کد فعلی پیاده‌سازی نشده |

این جدول ادعای «صفر مجوز در APK نهایی» نیست؛ مجوزهای بومی باید از خروجی واقعی تولید و بررسی شوند. توسعهٔ iOS فعلاً خارج از محدودهٔ تست و انتشار است.

## پیش‌نیازهای انتشار رسمی

قبل از انتشار در فروشگاه‌ها یا عرضهٔ تجاری، لازم است: مشخصات مالک/متولی و راه ارتباطی معتبر افزوده شود؛ فهرست همهٔ سرویس‌های میزبانی و شخص ثالث و داده‌های جمع‌آوری‌شده ممیزی گردد؛ وضعیت کوکی، تبلیغات، تحلیل رفتار، خرید، اعلان و همگام‌سازی به‌روزرسانی شود؛ حقوق استفاده از تصویرها، فونت‌ها، صداها و داستان روشن شود؛ بیانیهٔ حریم خصوصی و داده‌های فروشگاه با رفتار واقعی بیلد نهایی تطبیق داده شوند؛ و همهٔ تغییرات مهم با تاریخ نسخه ثبت شوند.

## کنترل پذیرش

- `npm test` و `npm run build` در پوشهٔ `game/` باید موفق باشند.
- گزینهٔ قوانین از هر سه ورودی باز شود؛ «بازگشت» و Escape کاربر را به صفحهٔ مبدأ بازگرداند.
- تغییر زبان در زمان نمایش قوانین، بدون بسته‌شدن پنجره، ترجمه و وضعیت باز/بسته بودن بخش‌ها را حفظ کند.
- در نمایشگر باریک، متن قابل اسکرول، خوانا و با `dir=rtl/ltr` درست باشد.
- هیچ درخواست واقعی مجوز دوربین، میکروفون، مکان یا اعلان برای صرفاً نمایش این صفحه ایجاد نشود.
- تغییر این متن **نباید** ذخیرهٔ بازی، قیمت‌ها، منابع یا قوانین اجرایی ساخت را تغییر دهد.
