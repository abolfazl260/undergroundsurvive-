# ارتقای سطح اتاق‌ها — `feature/room-upgrades`

## محدوده
- ارتقای اتاق‌های موجود (از جمله اتاق فرمان) از سطح ۱ به ۲ و سپس ۳.
- لمس اتاق در ابزار «ارتقا» فقط پیش‌نمایش است؛ افزایش سطح و کسر سکه **پس از تأیید صریح** انجام می‌شود.
- نمایش سطح فعلی، شاخص ظرفیت فعلی/بعدی و هزینهٔ سطح بعد؛ غیرفعال‌شدن دکمه در کمبود سکه یا حداکثر سطح.
- قیمت از سطح فعلی هنگام اجرای `GameSession.upgradeRoom(id)` محاسبه می‌شود؛ خطا نباید نقشه یا کیف پول را تغییر دهد.
- برجسته‌سازی سطح در تصویر بازی؛ ذخیره‌ و بازیابی با قالب فعلی بدون مهاجرت.

## شاخص‌های اسمی آزمایشی

| اتاق | شاخص | سطح ۱ | سطح ۲ | سطح ۳ |
| --- | --- | ---: | ---: | ---: |
| فرمان | ظرفیت هماهنگی (واحد) | ۱ | ۲ | ۳ |
| مسکونی | ظرفیت اسکان (نفر) | ۲ | ۴ | ۶ |
| نیروگاه | توان اسمی برق (واحد) | ۱۰ | ۱۵ | ۲۰ |
| گلخانه | ظرفیت کشت (واحد) | ۸ | ۱۲ | ۱۶ |
| درمانگاه | ظرفیت درمان (نفر) | ۲ | ۳ | ۴ |
| کارگاه | ظرفیت کارگاه (واحد) | ۵ | ۸ | ۱۱ |
| انبار | ظرفیت ذخیره (واحد) | ۵۰ | ۷۵ | ۱۰۰ |
| معدن | توان اسمی استخراج (واحد) | ۵ | ۸ | ۱۱ |

**توجه:** شاخص‌ها ظرفیت اسمی‌اند؛ هنوز تولید و مصرف واقعی منابع یا درآمد خودکار نیستند. اتصال به ماژول منابع در برنچ مستقل انجام می‌شود.

قیمت ۱→۲ برابر دو برابر قیمت ساخت و قیمت ۲→۳ برابر سه برابر قیمت ساخت است؛ فرمان به‌ترتیب ۵۰۰ و ۷۵۰ سکه. قیمت‌ها، موجودی شروع، فرمت ذخیره و دیگر ابزارها تغییر نکرده‌اند.

## تست
`cd game && npm install && npm test && npm run build`

اقتصاد این نسخه صرفاً محلی است؛ در بازی آنلاین کنترل سطح و پرداخت باید سمت سرور و در تراکنش اتمیک انجام شود.
