# چرخهٔ تولید و مصرف منابع

پیاده‌سازی در `feature/resource-production` با ماژول مستقل `game/src/modules/economy/resources.ts`.

## قوانین نمونهٔ اولیه

- هر **۵ ثانیه زمان فعال بازی** یک چرخه اجرا می‌شود؛ هنگام توقف بازی یا بسته‌بودن صفحه هیچ درآمد آفلاینی محاسبه نمی‌شود. جهش‌های طولانی در هر فراخوانی حداکثر ۶۰ ثانیه شمرده می‌شوند.
- منابع غیرسکه‌ای: **برق، غذا، سنگ معدن، تجهیزات**. این موجودی‌ها مستقل از کیف پول سکه و قیمت‌های ساختمان هستند.
- منابع اولیه: ۱۲ برق و ۱۲ غذا، صفر معدن و تجهیزات. ظرفیت هر منبع به‌صورت مستقل ۳۰ واحد است و هر انبار بر اساس سطحش ۵۰/۷۵/۱۰۰ واحد به آن اضافه می‌کند.
- نیروگاه به‌ترتیب سطح ۱۰/۱۵/۲۰ برق تولید می‌کند. اتاق فرمان به تعداد سطح خود برق مصرف می‌کند.
- مسکونی به اندازهٔ ظرفیت اسکان (۲/۴/۶) غذا و نصف آن برق (با گردکردن رو به بالا) مصرف می‌کند.
- گلخانه ۸/۱۲/۱۶ غذا تولید و نصف آن برق مصرف می‌کند؛ معدن ۵/۸/۱۱ سنگ تولید و نصف آن برق مصرف می‌کند.
- کارگاه ۵/۸/۱۱ تجهیزات می‌سازد و به اندازهٔ نصف خروجی خود برق و سنگ مصرف می‌کند.
- درمانگاه به اندازهٔ ظرفیت درمان خود برق و یک واحد تجهیزات مصرف می‌کند (درمان جداگانه هنوز توسعه نیافته است).
- ترتیب پردازش ثابت است: نیروگاه، فرمان، مسکونی، گلخانه، معدن، کارگاه، درمانگاه؛ بدون وابستگی به ترتیب ذخیره یا ساخت اتاق‌ها.
- اگر یکی از ورودی‌ها کافی نباشد، کل عملیات همان اتاق غیرفعال می‌شود؛ هیچ ورودی‌ای برای عملیات ناموفق مصرف نمی‌شود. هشدار کمبود و تعداد اتاق‌های غیرفعال در UI نمایش داده می‌شود.
- در سقف ظرفیت، تولید اضافی دور ریخته نمی‌شود بلکه از ابتدا متوقف می‌شود؛ منابع هنگام حذف انبار به سقف جدید محدود می‌شوند.
- تغییر تعداد/سطح اتاق‌ها در چرخهٔ بعد اثر می‌گذارد. ارتقا، ساخت‌وساز، جابه‌جایی و تخریب قوانین سکه‌ای سابق را حفظ می‌کنند.

## ذخیره، مهاجرت و تست

`GameSnapshot` نسخهٔ **۳** شامل `resources` است؛ ذخیره‌های سالم نسخهٔ ۲ به منابع اولیه مهاجرت می‌کنند و نقشه‌های قدیمی نسخهٔ ۱ همچنان پشتیبانی می‌شوند. تعداد چرخه‌ها، ماندهٔ زمان تا چرخه بعد، موجودی و آخرین کمبودها ذخیره می‌شوند. هنگام بازشدن دوباره، گذشت زمان در غیاب بازی احتساب نمی‌شود.

```bash
cd game
npm test
npm run build
```

اقتصاد در مرورگر **آزمایشی و قابل‌دست‌کاری** است، نه یک اقتصاد چندنفرهٔ امن. قبل از انتشار آنلاین، مدیریت ساعت/منابع/قوانین و تراکنش‌های اتمیک باید به سرور منتقل شود.
