# سیستم زمین، طبقات و اتاق‌ها — نسخهٔ آزمایشی 0.2

> وضعیت: پیاده‌سازی آزمایشی در کلاینت وب؛ هنوز اقتصاد، حساب و سرور آنلاین متصل نشده‌اند.

## محدودهٔ اجراشده

- Grid دوبعدی ۱۴ ستون، سطح زمین `y=0`، دو طبقه بالاتر (`y=1,2`) و چهار ردیف زیرزمین (`y=-1..-4`).
- محدودهٔ ساخت محدود است و مقادیر قابل تنظیم در `game/src/modules/world/grid.ts` تعریف شده‌اند.
- مسیرهای زیرزمینی اولیه باز هستند؛ برای حفاری خانه‌های جدید، خانه باید **مجاور خانهٔ باز** باشد.
- ساخت در زیرزمین فقط روی خانهٔ حفاری‌شده ممکن است؛ ساخت روی طبقات بالاتر فقط پس از آزادکردن طبقه و با **تکیه‌گاه زیر تمام عرض اتاق** مجاز است.
- چهار اتاق قابل ساخت با عرض دو خانه: مسکونی، نیروگاه، گلخانه و درمانگاه؛ اتاق فرمان اولیه قابل تخریب و انتقال نیست.
- پیش‌نمایش سبز/قرمز، جلوگیری از هم‌پوشانی، ابزار جابه‌جایی، تخریب و ارتقا تا سطح ۳.
- حذف یا انتقال اتاقی که باعث بی‌تکیه‌گاه‌شدن اتاق‌های بالاتر شود رد می‌شود.
- ذخیرهٔ موقت تمام وضعیت در `localStorage` با `schemaVersion=1` و امکان بازنشانی کامل.
- تست‌های واحد برای مرز نقشه، حفاری، طبقات، تکیه‌گاه، اعتبارسنجی ساخت، جابه‌جایی، تخریب و بازگردانی داده.

## استفاده در مرورگر

[اجرای نمونهٔ آنلاین در GitHub Pages](https://abolfazl260.github.io/undergroundsurvive-/) — توجه: ذخیره روی مرورگر شخصی است و بین دستگاه‌ها همگام نمی‌شود.


از داخل `game/` دستورهای `npm install` و `npm run dev` را اجرا کنید و آدرس نمایش‌داده‌شده را باز کنید.

1. **ساخت:** یک اتاق انتخاب کنید و روی خانهٔ خالیِ باز بزنید.
2. **حفاری:** ابزار حفاری را فعال کنید و روی خاک زیرزمین که کنار فضای باز است بزنید.
3. **طبقه:** دکمهٔ «بازکردن طبقه» را بزنید؛ برای ساخت آن طبقه، ابتدا در زیرش اتاق بسازید.
4. **جابه‌جایی:** ابتدا روی اتاق و سپس روی محل مقصد بزنید؛ کلیک مجدد روی همان اتاق انتخاب را لغو می‌کند.
5. **تخریب و ارتقا:** ابزار مربوط را فعال کنید و روی اتاق بزنید.
6. **بازنشانی:** نقشه، حفاری‌ها و ارتقاهای آزمایشی به حالت اولیه برمی‌گردند.

## جداسازی ماژول‌ها

| مسیر | مسئولیت |
| --- | --- |
| `modules/world/grid.ts` | مختصات و محدودیت شبکه |
| `modules/world/terrain.ts` | بازبودن زمین، حفاری، آزادکردن طبقات |
| `modules/building/catalog.ts` | تعریف انواع اتاق |
| `modules/building/placement.ts` | اعتبارسنجی محل و تکیه‌گاه |
| `modules/building/layout.ts` | عملیات ساخت، حذف، انتقال، ارتقا، Snapshot |
| `platform/localSave.ts` | ذخیرهٔ مرورگریِ موقت |
| `app/GameScene.ts` | فقط رندر و تعامل Phaser |
| `main.ts` | اتصال ابزارهای رابط کاربری به صحنه |

## محدودیت‌ها و مرحلهٔ بعد

- **هیچ اعتبار اقتصادی یا امنیت آنلاین** وجود ندارد: همهٔ ساخت‌ها، حفاری‌ها و ارتقاها فعلاً رایگان‌اند؛ ذخیرهٔ مرورگر قابل تغییر توسط کاربر است.
- محدودیت عرض زمین و تعداد طبقات برای نمونهٔ اولیه است و هنوز **گسترش بی‌نهایت نقشه، مسیر‌یابی آدمک‌ها، سازه‌های چندطبقه و حفاری واقعی با زمان/سکه** اضافه نشده‌اند.
- اطلاعات نمایشی باید در فاز اتصال Supabase به دستورات معتبر سمت سرور تبدیل شوند؛ کلاینت صرفاً پیش‌نمایش خواهد داد.
- در صورت تغییر ساختار ذخیرهٔ محلی، Migration لازم است؛ نسخهٔ داده فعلاً `1` است.
- آزمایش عملی روی دستگاه‌های موبایل و کیفیت لمس هنوز لازم است.
