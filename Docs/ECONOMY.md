# سیستم سکه و هزینهٔ ساخت — برنچ مستقل

> وضعیت: نمونهٔ اولیهٔ محلی در برنچ `feature/coins-construction-costs`؛ تا زمان Merge در `main` منتشر نمی‌شود.

## محدودهٔ پیاده‌سازی

- ماژول مستقل `game/src/modules/economy/` برای **فهرست قیمت‌ها**، **کیف پول و سابقهٔ تراکنش‌ها**، **اجرای امن عملیات محلی به‌صورت یک گام قابل برگشت**.
- موجودی شروع بازی ۱۵۰۰ سکه و کمک‌هزینهٔ اختیاری **یک بار ۵۰۰ سکه** برای تست.
- قیمت ساخت هفت نوع اتاق، هزینهٔ حفاری، آزادکردن طبقات و ارتقای اتاق‌ها تا سطح ۳.
- کسر سکه **فقط هنگام موفقیت عملیات**؛ ساخت نامعتبر یا کمبود موجودی نباید سکه را کاهش دهد.
- در این نسخه جابه‌جایی/تخریب رایگان است و **بازپرداخت سکه ندارند**.
- نمایش موجودی و قیمت اتاق‌ها، وضعیت دکمهٔ کمک‌هزینه، هزینهٔ طبقهٔ بعدی و شش تراکنش آخر در رابط کاربری.
- ذخیرهٔ آزمایشی در `localStorage` با قالب `game:v2`، حفظ نقشهٔ قدیمی `base:v1` هنگام مهاجرت و ثبت دفترکل در ذخیرهٔ جدید.
- تست‌های واحد اقتصاد و ادامهٔ تست‌های قبلی Grid و ساختمان.

## مرز امنیتی

**این نسخه اقتصاد آنلاین و ضدتقلب نیست.** تمام داده‌ها از جمله موجودی سکه در مرورگر ذخیره می‌شوند و بازیکن می‌تواند آن‌ها را تغییر دهد. کنترل دفترکل در این مرحله فقط برای جلوگیری از خطای تصادفی یا فرمت نامعتبر است و امنیت ایجاد نمی‌کند.

در مرحلهٔ Supabase:
1. موجودی، قیمت‌ها، مجوز عملیات و وضعیت نقشه در سرور نگهداری و بررسی شود.
2. پرداخت و تغییرات نقشه در یک تراکنش PostgreSQL/RPC معتبر ثبت شوند.
3. `operation_id` یکتا برای idempotency و کنترل نسخهٔ پایگاه برای جلوگیری از race condition اضافه شود.
4. RLS، سیاست‌های مالکیت و کنترل دسترسی پیاده‌سازی شوند.
5. کمک‌هزینهٔ آزمایشی حذف یا فقط در محیط توسعه فعال شود.

## ساختار داخلی

| مسیر | هدف |
| --- | --- |
| `economy/pricing.ts` | تعریف یک‌جای تمام قیمت‌ها |
| `economy/wallet.ts` | کیف پول و تراکنش‌ها |
| `economy/session.ts` | هماهنگ‌سازی نتیجهٔ عملیات ساختمان با پرداخت سکه |
| `platform/localSave.ts` | ذخیرهٔ موقت و مهاجرت v1 به v2 |
| `app/GameScene.ts` | نمایش نتیجهٔ عملیات، بدون تعیین قیمت در Phaser |
| `main.ts` | نمایش موجودی و قیمت‌ها در UI |

## تست و توسعه

```bash
cd game
npm install
npm test
npm run build
```

در نسخهٔ فعلی درآمد خودکار منابع، مأموریت‌های پاداش‌دهنده، پرداخت واقعی و سرور وجود ندارند. کمک‌هزینهٔ یک‌باره فقط برای آزمایش مسیر کمبود موجودی ارائه شده است.

این سند مربوط به برنچ مستقل است. ادغام آن در `main` باید پس از بازبینی و تست انجام شود.
