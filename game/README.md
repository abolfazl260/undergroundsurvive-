# Underground Survive — Web Prototype

این پوشه نخستین نسخهٔ اجرایی وب بازی با **Phaser 3.90، TypeScript و Vite** است.

## پیش‌نیاز

- Node.js 22.12 یا جدیدتر
- npm

## اجرای محلی

از ریشهٔ مخزن:

```bash
cd game
npm install
npm run dev
```

سپس آدرس **http://localhost:5173** را در مرورگر باز کنید. گزینه‌های زیر نیز در دسترس‌اند:

```bash
npm run test
npm run build
npm run preview
```

بیلد تولیدی در `game/dist/` ساخته می‌شود و می‌توان آن را روی سرویس میزبانی فایل استاتیک منتشر کرد. نسخهٔ وب از طریق [GitHub Pages](https://abolfazl260.github.io/undergroundsurvive-/) نیز منتشر شده است؛ بیلد محلی همچنان برای توسعه استفاده می‌شود.

## امکانات فعلی (نسخهٔ آزمایشی 0.2)

- شبکهٔ ۱۴ ستونی شامل سطح زمین، دو طبقهٔ بالای زمین و چهار ردیف زیرزمین
- حفاری خانه‌های مجاور مسیر باز در زیرزمین
- بازکردن تدریجی طبقات بالای زمین و الزام تکیه‌گاه برای ساخت در ارتفاع
- انتخاب اتاق، ساخت، جلوگیری از تداخل، جابه‌جایی، تخریب و ارتقا تا سطح ۳
- ذخیرهٔ خودکار محلی در مرورگر و بازنشانی کامل وضعیت
- پیش‌نمایش سبز/قرمز و تست واحد قوانین زمین و اتاق‌ها
- نمایش آدمک متحرک آزمایشی بدون مسیر‌یابی واقعی
- تصاویر شش نوع اتاق با Sprite Sheet سبک WebP، سازگار با موبایل و وب

## اقتصاد آزمایشی برنچ
- نمایش موجودی سکه و هزینهٔ ساخت هفت اتاق، حفاری، آزادکردن طبقات و ارتقا.
- موجودی اولیه ۱۵۰۰ سکه؛ امکان دریافت کمک‌هزینهٔ یک‌بارهٔ ۵۰۰ سکه برای تست.
- اعتبارسنجی موجودی و ثبت تاریخچهٔ پرداخت؛ مانع شدن از کسر سکه هنگام شکست عملیات.
- مهاجرت ذخیرهٔ قدیمی `base:v1` به `game:v2` با نگه‌داشتن نقشه و اتاق‌ها.
- اجرا و مشاهده از طریق `npm run dev` روی همین برنچ؛ **لینک GitHub Pages به نسخهٔ `main` اشاره دارد و این تغییرات را تا Merge نشان نمی‌دهد.**
- سند [قیمت‌ها و اقتصاد](../Docs/ECONOMY.md)

## محدودیت‌های فعلی

- هیچ‌یک از عملیات هنوز به Supabase و حساب آنلاین متصل نیست.
- **سیستم سکه و هزینه‌ها در برنچ آزمایشی `feature/coins-construction-costs` اضافه شده است؛ فقط زمان ساخت و اثر تولیدی ارتقا هنوز وجود ندارند.**
- حفاری و بازکردن طبقات در محدودهٔ فعلی نقشه انجام می‌شوند، نه در یک جهان نامحدود.
- داده‌های اقتصادی و نقشه در `localStorage` همین مرورگر ذخیره می‌شوند و برای رقابت آنلاین معتبر نیستند.
- نسخه‌های Capacitor و PWA هنوز آماده نشده‌اند.

## راهنمای معماری

- `src/modules/world`: مختصات و شبکهٔ مستقل از Phaser
- `src/modules/building`: تعریف اتاق، اعتبارسنجی و وضعیت نقشه
- `src/app`: صحنهٔ Phaser و اتصال ماژول‌ها
- `src/main.ts`: اتصال UI مرورگر و بازی

**قانون:** اطلاعات و قواعد اصلی جهان و ساختمان به Phaser وابسته نشوند. در گام بعد می‌توان آداپتورهای Supabase و ذخیرهٔ امن آنلاین را بدون بازنویسی کد رندر اضافه کرد.

## تصاویر اتاق‌ها

شش تصویر دو‌بعدی در `public/assets/rooms/room-atlas.webp` قرار دارند. هر فریم ۱۶۰×۵۳ پیکسل است و در `src/app/roomArt.ts` به نوع اتاق نگاشت می‌شود: مسکونی (۰)، فرمان و آسانسور (۱)، کارگاه (۲)، انبار (۳)، نیروگاه (۴) و معدن (۵).

`GameScene.preload` تصویر را یک‌بار بارگذاری می‌کند و `paintRooms` متناسب با ابعاد اتاق در Grid نمایش می‌دهد. سه نوع کارگاه، انبار و معدن به منوی ساخت افزوده شده‌اند. گلخانه و درمانگاه تا تولید تصاویر اختصاصی همچنان با طراحی رنگی قبلی نمایش داده می‌شوند. اگر فایل تصویر بارگذاری نشود، رندر رنگی برای همهٔ اتاق‌ها فعال می‌ماند.

تصویر اصلی شش اتاق با کیفیت بالا ساخته شده و Sprite Sheet صرفاً خروجی بهینه‌شده برای نسخهٔ فعلی وب و موبایل است. برای اتاق‌های چندبخشی در آینده باید به‌جای کشیدن تصویر روی هر عرض دلخواه، قطعات قابل توسعهٔ جداگانه طراحی شود.
