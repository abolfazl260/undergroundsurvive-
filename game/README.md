# Underground Survive — Web Prototype

این پوشه نخستین نسخهٔ اجرایی وب بازی با **Phaser 3.90، TypeScript و Vite** است.

## پیش‌نیاز

- Node.js 22.12 یا جدیدتر
- npm

## اجرای محلی

از ریشهٔ مخزن:

```bash
cd game
npm install
npm run dev
```

سپس آدرس **http://localhost:5173** را در مرورگر باز کنید. گزینه‌های زیر نیز در دسترس‌اند:

```bash
npm run test
npm run build
npm run preview
```

بیلد تولیدی در `game/dist/` ساخته می‌شود و می‌توان آن را روی سرویس میزبانی فایل استاتیک منتشر کرد. **هنوز دامنه یا استقرار عمومی پیکربندی نشده است.**

## امکانات نمونهٔ اولیه

- نمایش دوبعدی سطح زمین و چند طبقهٔ زیرزمینی با شبکهٔ Grid
- تعدادی اتاق از پیش ساخته‌شده
- انتخاب چهار نوع اتاق و ساخت در خانه‌های مجاز
- پیش‌نمایش سبز/قرمز مکان ساخت و جلوگیری از تداخل و خروج از محدوده
- یک آدمک نمونه با انیمیشن حرکت ساده
- بازنشانی نقشه و تست‌های واحد قوانین جای‌گذاری
- چیدمان سازگار با نمایشگر کوچک، بدون وابستگی به تصویر یا فایل گرافیکی خارجی

## محدودیت‌های فعلی

- اتاق‌های ساخته‌شده فقط در حافظه‌اند؛ با Refresh از بین می‌روند.
- حساب کاربری، Supabase، ذخیرهٔ آنلاین و سکه هنوز متصل نیستند.
- ساخت زیرزمین در نسخهٔ آزمایشی آزاد است و حفاری/قفل‌گشایی پیاده‌سازی نشده است.
- حرکت آدمک فعلاً نمایشی است و مسیر‌یابی، تخصص‌ها و فرمان‌های کاری ندارد.
- نسخهٔ Android/iOS هنوز با Capacitor بسته‌بندی نشده است.
- PWA و استقرار عمومی نیز مرحلهٔ بعد هستند.

## راهنمای معماری

- `src/modules/world`: مختصات و شبکهٔ مستقل از Phaser
- `src/modules/building`: تعریف اتاق، اعتبارسنجی و وضعیت نقشه
- `src/app`: صحنهٔ Phaser و اتصال ماژول‌ها
- `src/main.ts`: اتصال UI مرورگر و بازی

**قانون:** اطلاعات و قواعد اصلی جهان و ساختمان به Phaser وابسته نشوند. در گام بعد می‌توان آداپتورهای Supabase و ذخیرهٔ امن آنلاین را بدون بازنویسی کد رندر اضافه کرد.
